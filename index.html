04 field notes

Small habits. Fewer detours.

A

Search scope is a decision.

Use Find for the active file, Find in Files for folders in the current project or window, and Goto Anything when you know what you want to reach but not its exact path.

B

Regex is a tool, not a default.

Use regex when the pattern matters, not just the literal text. For a simple rename, plain text is easier to review before you choose Replace All.

C

Let indexing do the walking.

Wait for indexing to finish before judging navigation. Project symbols, definitions, references, and completions are more useful once Sublime has scanned the open project.

D

Build output is a map.

Run a build, then use Next build result and Previous build result to move through errors instead of hunting from the top.
